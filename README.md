# Responsive Tea Website

A responsive tea website built as part of the **Sheryians Coding School
Cohort 3.0** assignment.

The project recreates a modern tea-brand landing page using HTML and
CSS, with a strong focus on responsive layouts, typography, cards,
sections, and mobile-friendly design.

## Overview

This project is a frontend recreation inspired by the Two Leaves and a
Bud tea website. It includes multiple sections designed to showcase
products, reviews, brand information, tea lattes, a journal section, and
a responsive footer.

live link :
https://responsive-task-sheriyans-cohort-3.vercel.app/

The page is built from scratch using:

-   HTML5
-   CSS3
-   Remix Icon
-   Custom fonts
-   CSS Flexbox
-   CSS Grid
-   CSS animations
-   Responsive media queries

## Sections

### 1. Hero

Introduces the tea brand with a large background image, headline,
description, and Shop Now button.

### 2. Best Sellers

Displays tea products in horizontally scrollable cards with:

-   Product image
-   Category
-   Rating
-   Product name
-   Price
-   Description
-   Add button

### 3. Discover

Allows visitors to explore tea based on different preferences and
categories such as:

-   A Sweet Treat
-   Evening Unwind
-   Focused & Clear
-   Caffeine
-   Caffeine-Free
-   Whole Leaf
-   Over Ice
-   Lattes
-   Black Tea
-   Green Tea
-   Herbal Tea
-   Organic

### 4. Our Origins

A brand story section explaining the company's origins and highlighting
its values around quality, people, planet, and transparent sourcing.

### 5. Reviews

A horizontally scrollable collection of customer reviews connected to
tea products.

### 6. Cafe & Wholesale Partners

A split layout featuring an image alongside information about cafe and
wholesale partnerships.

### 7. Tea Lattes

A promotional section for the Matcha Latte Mix with product information
and a Shop Now CTA.

### 8. Tea Journal

A collection of article cards covering recipes, matcha, caffeine, and
tea-related topics.

### 9. About

A large promotional section introducing the people, places, and purpose
behind the tea blends.

### 10. Footer

Includes:

-   Newsletter signup
-   Social icons
-   Tea varieties
-   Collections
-   Lattes
-   Learning resources
-   Tea Journal
-   Support links
-   Copyright information

## Responsive Design

The website uses CSS media queries to adapt the layout for screens below
`768px`.

Mobile adjustments include:

-   Collapsed navigation links
-   Mobile menu icon
-   Smaller typography
-   Single-column layouts
-   Horizontally scrollable cards
-   Adjusted section spacing
-   Responsive product and review cards
-   Stacked footer content
-   Mobile-friendly buttons and inputs

## Getting Started

Clone the repository:

``` bash
git clone https://github.com/AxodusYT/responsive-task-sheriyans-cohort-3.git
```

Move into the project directory:

``` bash
cd responsive-task-sheriyans-cohort-3
```

Open `index.html` in your browser.

For the best development experience, use the **Live Server** extension
in VS Code.
